# /reality-check — звір із реальністю, перш ніж діяти

**Головна ідея:** документ — це фото минулого. Код та інфра — це «зараз». Перш ніж витратити годину на те, що каже документ/аудит/лист — витрать 5 хвилин, щоб перевірити, чи це ще правда.

**Твоя ціна питання (з реальних випадків):** 3 «критичні тривоги» виявились давно закритими → 1.5 год марно. «Ми на Neon» → насправді Railway → 2 год інфра-аудиту не туди. Цей скіл ловить саме такі.

---

## Крок 1 — стоп, не починай діяти

Почув/прочитав твердження про стан («X зламано», «Y мертве», «задача критична», «N багів», «ми юзаємо Z») — НЕ кидайся чинити чи панікувати. Спершу постав одне питання:
> **Звідки це твердження і коли воно писалось?**

Джерела за спаданням довіри: живий код/інфра (істина) → свіжий лог/тест (майже істина) → PR/git (недавнє) → CLAUDE.md/MEMORY/аудит/лист (могло застаріти) → чиясь памʼять (найризикованіше).

## Крок 2 — знайди ЖИВЕ джерело для цього типу твердження

Не вір документу — піди до першоджерела, що показує стан ЗАРАЗ:

| Твердження каже… | Жива перевірка (істина зараз) |
|---|---|
| «символ/поле/функція мертві, не використовуються» | `grep` по всьому коду — і по рядкових ключах теж (може викликатись через `await import`, рядок конфіга, шаблон) |
| «задача критична / досі відкрита / не зроблена» | Сам код + `git log`/PR по темі — а не статус у документі чи листі |
| «ми на базі/хостингу/сервісі X» | Панель провайдера + `env`/конфіг у репо — не опис у README/CLAUDE.md |
| «у нас N вразливостей / застарілих пакетів» | Перезапусти аудит ЗАРАЗ (`npm audit` тощо) — стара цифра майже завжди інша |
| «це вже зламано / не працює» | Відтвори сам: виклич ендпоінт, відкрий сторінку, запусти тест |

## Крок 3 — звір: твердження == реальність?

- **Збіглось** → тривога справжня, дій (можеш перейти до `/pre-deploy` чи `debug`).
- **Не збіглось** → це міф застарілого документа. НЕ витрачай години. Зроби дві речі:
  1. Скажи прямо: «перевірив — насправді Y, документ застарів».
  2. **Онови документ** (CLAUDE.md/MEMORY/лист) на місці — щоб та сама брехня не зʼїла час наступного разу.

## Крок 4 — рахуй, скільки зекономив

Одне речення в кінці: «звірка зайняла 5 хв, зберегла ~N год марної роботи». Це робить користь відчутною і закріплює звичку.

## Правило скіла
Жодне твердження про стан коду/інфри/задачі не запускає роботу, поки не звірене з живим джерелом. «Документ так каже» — це привід перевірити, а не привід діяти. Три застарілі тривоги за один день довели: сумнів дешевший за годину не туди.
