# Шаблон завдання для нічного лупа

Підстав своє в `<кутові дужки>` і віддай через `/ralph-loop`.
Усе, що НЕ в дужках, лишай — кожен рядок закриває конкретну граблю.

---

```text
Працюй автономно, я сплю. Питань не став — рішення приймай сам.

ПРОЄКТ: <абсолютний шлях> (<стек>, гілка <база>)
ПЛАН:   <абсолютний шлях до файлу плану, якщо є>

СПОЧАТКУ: git checkout -b <гілка-роботи>
На <база> не комітити. Не мерджити. Не деплоїти. Прод не чіпати.

ЕТАП 1 (швидке, ~15 хв):
<1-3 дрібні виправлення, які дають користь навіть якщо ніч обірветься>
Після етапу: <команда збірки>. Не збирається — відкати й опиши чому. Коміт.

ЕТАП 2 (головне): <що саме, скільки одиниць>
Джерело даних: <файл>. Шаблон/споживач: <файл>.

Обробляй ПО ОДНІЙ одиниці за ітерацію. Для кожної:
- <вимога до обсягу: N-M слів / рядків>
- <вимога до змісту: чим ця одиниця відрізняється від решти>
- ЗАБОРОНЕНО: перефразовувати той самий текст іншими словами. Якщо про
  одиницю нема чого сказати конкретного — зроби коротше, але правдиво.
  Нічого не вигадуй: <адреси, ціни, дати, телефони> бери лише з файлів
  проєкту, інакше пиши узагальнено.
- Після кожних 5 одиниць: <команда збірки> + git commit.

ГЕЙТ (обов'язково): після кожних 10 одиниць запусти
  <команда гейта>
Поріг: <величина> має бути <менше/більше> <число>.
Не проходить — переписуй ті одиниці, ДАЛІ НЕ ЙДИ.

ЕТАП 3: <решта роботи>. Коміт після кожної.

ЖУРНАЛ: веди NIGHT-LOG.md у корені проєкту — що зроблено, що не вийшло,
цифри до/після, і окремо «чого свідомо НЕ робив і чому».
Це я читаю вранці першим.

ГОТОВО, коли: етапи 1-3 завершені, <команда збірки> проходить,
<величина гейта> <поріг>, усе закомічено в <гілка-роботи>.
Забуксував двічі на одному — пропусти, запиши в журнал, іди далі.
```

---

## Чому кожен рядок на місці

| Рядок | Граблі, які він закриває |
|---|---|
| «Питань не став» | Луп стає на першому уточненні й чекає до ранку |
| Окрема гілка, не мерджити | Вранці рішення ухвалює людина, не нічний агент |
| Етап 1 = швидке | Ніч обірвалась на 30 % — цінне вже зроблено |
| Пакетами по 5 | По одній — шум комітів; усі разом — нічого не відкотиш |
| Гейт на 10 | Ловить деградацію на середині, а не після 36-ї одиниці |
| «ДАЛІ НЕ ЙДИ» | Без цього агент занотує провал і поїде далі |
| «Нічого не вигадуй» | Вигадана ціна/адреса на сайті гірша за її відсутність |
| «Чого свідомо НЕ робив» | Ранкове «а це чому пропущено?» знімається одразу |
| ГОТОВО у цифрах | Словесне «готово» агент видасть завжди |
| «Забуксував двічі» | Одна складна одиниця з'їдає всю ніч |

## Запуск

```bash
cd "<шлях до проєкту>" && claude --dangerously-skip-permissions
```

Далі `/ralph-loop` і вставити завдання. Без прапорця луп стане на першому
запиті дозволу.
