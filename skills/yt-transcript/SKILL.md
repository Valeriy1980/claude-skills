# yt-transcript

Вузький скіл: **посилання YouTube → файл транскрипту з таймкодами**. Аналіз —
окремо (video-analyzer), щоб кожен крок тестувався сам.

## Коли брати
- Є лінк на YouTube + треба текст/субтитри/переказ/аналіз.
- НЕ брати, якщо транскрипт уже вставлений у чат — тоді одразу `video-analyzer`.

## Як використати
1. Запусти fetch — він качає лише субтитри (не відео), пріоритет мов uk→ru→en,
   і чистить (дедуп rolling-дублів авто-субтитрів, прибирає теги):
   ```bash
   bash ~/.claude/skills/yt-transcript/tools/fetch.sh "<URL>" [out-dir]
   ```
   stdout = шлях до `.transcript.txt`. За замовчуванням у `~/Downloads/yt-transcripts/`.
2. Прочитай отриманий `.txt` і передай у `video-analyzer` (інсайти що впровадити)
   або `summarize` (стислий переказ) — за наміром користувача.

## Якщо HTTP 429 (Too Many Requests)
YouTube рейт-лімітить субтитри по IP. Це transient, не баг:
- зачекай і повтори за кілька хвилин;
- або (опт-ін, чіпає сесію браузера) автентифікуй запит:
  `YT_COOKIES_FROM_BROWSER=chrome bash .../fetch.sh "<URL>"` —
  cookies піднімають ліміт. Питай дозволу перед використанням cookies.

## Файли
- `tools/fetch.sh` — оркестратор (yt-dlp, 1 виклик, retry/sleep проти 429, вибір мови).
- `tools/clean_vtt.py` — VTT→чистий транскрипт (дедуп, таймкоди, блоки ~12с/200 знаків).

## Залежності
`yt-dlp` + `ffmpeg` (обидва вже встановлені). Оновити: `yt-dlp -U`.
