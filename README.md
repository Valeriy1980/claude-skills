# claude-skills

13 скілів для [Claude Code](https://claude.com/claude-code), зібраних із реальної щоденної роботи — не з теорії. Кожен виріс із конкретної помилки, яка колись коштувала часу.

Українською. Скіли самі підхоплюються за описом — кликати руками не треба.

> **English:** 13 Claude Code skills written in Ukrainian, grown from real day-to-day mistakes: pre-deploy verification, cross-vendor code review, autonomous overnight runs, UI variant exploration, and more.

## Встановлення

```bash
npx skills add Valeriy1980/claude-skills
```

Або вручну — скопіювати потрібну теку в `~/.claude/skills/`.

## Що всередині

### Не зламати те, що працює

| Скіл | Про що |
|---|---|
| **pre-deploy** | Чеклист перед незворотним кроком на прод. Змушує перевірити зміну на авторитетному шарі — порахувати в базі, глянути сам файл — а не «виглядає ок у браузері». Порядок: тест → перевір → **потім** мердж |
| **reality-check** | 5-хвилинна звірка твердження з живим джерелом, перш ніж витрачати години. Ловить застарілі документи, що породжують тривоги на порожньому місці |
| **multi-review** | Той самий код через 4 різні системи (Claude · Codex · Gemini · Cursor). Для змін, де сліпа пляма однієї моделі коштує тижня: оплати, авторизація, міграції |
| **contradiction-audit** | Шукає суперечності всередині одного довгого документа — звіту, PRD, договору |

### Не загубитись у великій задачі

| Скіл | Про що |
|---|---|
| **bigtask-map** | Розкладає велику туманну задачу на карту питань-рішень. Кожна сесія бере наступне питання, а не перечитує все заново — робота на кілька днів не розсипається |
| **night-loop** | Автономна нічна робота з **числовим критерієм готовності, який агент не може підробити**. Без такого критерію нічний прохід уранці рапортує «готово» про роботу, якої ніхто не міряв |
| **chat-handoff** | Стискає розмову в один блок для копіювання — свіжа сесія одразу знає, де ви спинились |

### Дизайн і UI

| Скіл | Про що |
|---|---|
| **ui-variants** | 3 структурно різні версії одного екрана на одному роуті з перемикачем `?variant=A/B/C`. Замість вгадування — дивишся живцем і обираєш |
| **design-before-after** | Рендерить сам елемент у реальному масштабі, щоб не-дизайнер побачив і проблему, і виправлення. Дизайн-огляд ставить діагноз — цей скіл робить фікс відчутним |

### Робота зі знанням

| Скіл | Про що |
|---|---|
| **yt-transcript** | Субтитри YouTube за посиланням → чистий транскрипт із таймкодами |
| **video-analyzer** | Транскрипт → тільки дія: викидає рекламу й самопіар, позначає сумнівне |
| **skill-quality** | Як писати скіли, щоб вони спрацьовували самі й не жерли контекст |
| **audit-rules-file** | Розбирає роздутий `CLAUDE.md`: пропозиції по одній, з твоїм підтвердженням, копія перед змінами |

## Як користуватись

Скіли підхоплюються автоматично — просто опиши задачу своїми словами. Або виклич прямо: `/pre-deploy`, `/ui-variants`.

Деякі спираються на зовнішні інструменти (`codex`, `cursor-agent`, `yt-dlp`) — якщо чогось нема, скіл скаже.
